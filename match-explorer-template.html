Use a CSV with the columns Year, Last Name, First Name, Program, Institution, City, and State. A student listed twice in the same year is treated as one student with a residency and a preliminary year. Optional columns: Type (containing “prelim”) and Latitude and Longitude, which put each pin at the exact institution. The included Python script creates those.
